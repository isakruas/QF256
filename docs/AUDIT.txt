QF256 data and source consistency checks

Run commands from the project root. Build results and compiler versions are
recorded in docs/VALIDATION.txt; statistical definitions are in
study/ANALYSIS_METHODS.txt and study/MODEL.md.

File integrity
  sha256sum -c docs/DELIVERY.sha256
  sha256sum -c docs/CORE.sha256
  sha256sum -c study/DATA.sha256
  sha256sum -c study/PHYSICAL.sha256

DELIVERY.sha256 covers checked-in files except itself. Verify it before
regenerating figures or tables. CORE.sha256 identifies complete numerical
source files; CORE-STATEMENTS.txt identifies those files with full-line
Fortran comments omitted. Data source identities are in
study/DATA_SOURCES.csv and study/physical_sources.tsv.

Build and regression checks
  make strict

This target treats Fortran and C compiler warnings as errors, runs the core,
I/O, CLI and API tests, checks the documented IQ/WAV examples, and rebuilds
the study summaries. Expected results include 88 core checks, 26 I/O checks
and 39 CLI checks. The waveform fixtures check the complete CF32 frame hash
and exact PCM sample values. These checks are separate from channel trials.

SNR-estimator checks
  make snr-validation

This runs the fixed-seed AWGN and official moderate/hard HF-channel cases in
study/validate_snr.f90. The retained numerical output is in
study/SNR_VALIDATION.csv. AWGN includes 128 estimator cases at each level;
fading statistics include only CRC-valid correct decodes, matching public
receiver availability.

Study-record checks
  make study-analysis

The Fortran analysis checks 3072 signal records representing 1536 cases
paired across power settings, and 6144 noise records: 2048 calibration
captures and 4096 check captures. Correct-message totals are 784/1536 for
unit-average power and 686/1536 for unit-peak power, with zero incorrect
acceptances. The noise-check set contains zero accepted messages.

The physical analysis checks 3072 records and uses each of the 1536 unique
waveforms once for bandwidth and PAPR distributions. Numerical tables are
generated by Fortran; study/plots.gp renders the figures from those tables.
The two indexed signal/noise replay commands and their expected values are
documented in study/REPRODUCTION_CHECK.txt.

Interpretation
The measurements cover the two specified HF profiles, six reference levels,
and a source ensemble of 71 random bits plus six fixed bits. Power settings
reuse cases. Calibration and noise-check seeds are disjoint; cross-role seed
coincidences and the scope of independence are documented in
study/ANALYSIS_METHODS.txt. Confidence intervals and interpolated thresholds
must be interpreted with these sampling conditions and the 2 dB grid.
