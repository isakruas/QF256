QF256 data and source consistency checks

Run commands from the project root. Historical v1.0 build results and compiler
versions are recorded in docs/VALIDATION.txt; statistical definitions are in
study/ANALYSIS_METHODS.txt and study/MODEL.md.

File integrity
  sha256sum -c docs/DELIVERY.sha256
  sha256sum -c docs/RUNTIME-CORE.sha256
  sha256sum -c study/DATA.sha256
  sha256sum -c study/PHYSICAL.sha256

DELIVERY.sha256 covers checked-in files except itself. Verify it before
regenerating figures or tables. RUNTIME-CORE.sha256 identifies the numerical
source files built and tested from the current checkout.

CORE.sha256, CORE-STATEMENTS.txt, and VALIDATION.txt are frozen v1.0 historical
records associated with the bundled measurements and technical report. They
must not be interpreted as hashes or validation results for the current
runtime. Verify the historical core manifest against tag v1.0.0, commit
93405683da7fc6c1e5f886e4ccca30850c7d3875. Data source identities are in
study/DATA_SOURCES.csv and study/physical_sources.tsv.

Build and regression checks
  make strict

This target treats Fortran and C compiler warnings as errors, runs the core,
I/O, CLI and API tests, checks the documented IQ/WAV examples, and rebuilds
the study summaries from the stored records. The test programs report their
current check counts. The 88 core, 26 I/O, and 39 CLI counts in VALIDATION.txt
describe the frozen v1.0 checkout, not the current runtime. The waveform
fixtures check the complete CF32 frame hash and exact PCM sample values. These
checks are separate from channel trials.

Historical SNR-estimator checks
  make snr-validation

The retained numerical output in study/SNR_VALIDATION.csv belongs to v1.0.
Exact regeneration requires the v1.0.0 tag and commit named above. Running the
target on the current HEAD compiles the current receiver and is a new
experiment; it is not evidence that the frozen v1.0 output was reproduced.

Study-record checks
  make study-analysis

The Fortran analysis checks 3072 signal records representing 1536 cases
paired across power settings, and 6144 noise records: 2048 calibration
captures and 4096 check captures. Correct-message totals are 784/1536 for
unit-average power and 686/1536 for unit-peak power, with zero incorrect
acceptances. The noise-check set contains zero accepted messages.

The physical analysis checks 3072 records and uses each of the 1536 unique
waveforms once for bandwidth and PAPR distributions. Numerical tables are
generated by Fortran; study/plots.gp renders the figures from those tables.
The two frozen v1.0 indexed signal/noise replay commands and their expected
values are documented in study/REPRODUCTION_CHECK.txt.

Interpretation
The measurements cover the two specified HF profiles, six reference levels,
and a source ensemble of 71 random bits plus six fixed bits. Power settings
reuse cases. Calibration and noise-check seeds are disjoint; cross-role seed
coincidences and the scope of independence are documented in
study/ANALYSIS_METHODS.txt. Confidence intervals and interpolated thresholds
must be interpreted with these sampling conditions and the 2 dB grid.
